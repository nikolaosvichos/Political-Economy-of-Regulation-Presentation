# Online Appendix: Coming of Age Under Trump
This repository includes the online appendix for the "Coming of Age Under Trump" paper. For now, the appendix is the `CURRENT_OnlineAppendix.html` file. To view the appendix, you just need to download the file and open it in your browser. I have also included a replication code file (`ReplicationCode.R`) for the main analysis. 

Note on wordcount: 
- The final wordcount for this paper was 3,298 words (I was not able to find a way to put this in the PDF rendering of the .qmd file.
- However, please note that the specific package used ('wordcount' by Andrew Heiss) has had some inaccuracies in the past, at least in my experience.

Note on the use of AI: 
- For the purposes of this paper, I only used AI in the following circumstances:
  - Coding improvements: In cases where the code simply did not work (and I was not able to find the answer on Stack Overflow), I used AI to help me streamline/troubleshoot some minor issues
  - Phrasing (infrequent): In cases where I was not sure about the correct phrasing of a sentence (since English is my second language), I used AI to help me figure out the correct phrasing.
